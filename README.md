# 🌌 Solar System Explorer

> Interactive 3D Solar System Visualization — Built with Three.js

An immersive, interactive 3D visualization of our solar system. Explore planets, moons, spacecraft, and learn fascinating facts about our cosmic neighborhood. Perfect for students, space enthusiasts, and curious minds!

![Preview](https://raw.githubusercontent.com/Satbhai444/Solar-System-Explorer/main/SS/Screenshot%202026-09-01%20210126.png)

## ✨ Features

### 🚀 Interactive Exploration
- **Click to Explore** — Click on any planet, moon, or spacecraft to learn more
- **3D Navigation** — Drag to rotate, scroll to zoom in/out
- **Smooth Animations** — Real-time orbital motion with adjustable speed

### 🎯 Planet Details
Every celestial body includes:
- Real scientific data (mass, diameter, orbital period, distance from sun)
- Fascinating facts and descriptions
- Beautiful visual representation

### 📤 Share Your View
- **Multiple Platforms** — Share to WhatsApp, Instagram, Twitter, Facebook, Telegram, Reddit
- **Multiple Formats** — Story (9:16), Post (1:1), Banner (16:9), Status, Header
- **Download PNG** — Save high-quality images of your current view

### 🗺️ Guided Tour
- **11-Step Journey** — From the Sun to Voyager 1
- **Progress Tracking** — Visual progress bar shows your tour progress
- **Jump to Any Planet** — Click Tour button in the info panel for any selected planet

### 🎨 Beautiful UI/UX
- **macOS Dock Style Controls** — Glassmorphism design
- **Dark/Light Theme** — Toggle between themes
- **Responsive Design** — Works on desktop, tablet, and mobile
- **Glassmorphism Panels** — Modern, translucent UI elements

### ⚙️ Controls
| Action | Control |
|--------|---------|
| Rotate | Drag anywhere |
| Zoom | Scroll wheel |
| Select | Click on planet |
| Orbits | Toggle orbit lines |
| Labels | Toggle planet names |
| Pause | Pause/resume animation |
| Speed | Adjust time speed (turtle → rabbit) |
| Tour | Guided exploration |
| Scale | Toggle real scale view |
| Eclipse | View eclipse mode |
| Share | Share current view |

- **Three.js r128** — 3D rendering
- **HTML5/CSS3** — Structure and styling
